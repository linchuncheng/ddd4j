# Markdown 文档生成规范

## 核心原则

- **生成 Markdown 文档时直接遵循本规范**
- 禁止使用章节序号（如 `1.1`、`1.1.1`），直接使用标题文本
- 列表内容优先表格化展示
- 精简冗余描述，保留核心信息（除非用户告知）

## 格式规范

### 章节标题

- **不使用章节序号**（如 `1.1`、`1.1.1`）
- 标题层级最多三级（`#`、`##`、`###`）

### 内容表格化

列表内容优先使用表格展示，提升可读性：

| 场景 | 示例 |
|------|------|
| 属性说明 | `参数名: username` → 表格列 |
| 层级对比 | 同级概念对比 |
| 正反对照 | 应该/不应该 |

### 精简原则

| 规则 | 说明 |
|------|------|
| 简化描述 | 去除解释性文字，用简洁短语替代长句 |
| 精简代码 | 去冗余注释，保留核心逻辑，合并相似示例 |
| 精简空行 | 段落间保留适当空行即可 |

### 标记保留

保留以下标记符号用于强调：

- ✅ 正确/推荐
- ❌ 错误/避免
- ⚠️ 警告/注意

## 处理流程对比

| 场景 | 方式 | 说明 |
|------|------|------|
| 新文档生成 | 直接遵循本规范 | AI 按规则输出 |
| 历史文档优化 | 使用 `/nice` 技能 | 脚本预处理 + AI 精加工 |

## 示例对比

| 原始（不推荐） | 优化后（推荐） |
|--------------|--------------|
| `## 1.1 接口规范`<br>`- 参数名: username`<br>`- 类型: String` | `## 接口规范`<br>`\| 参数 \| 类型 \|`<br>`\|--------\|--------\|`<br>`\| username \| String \|` |
